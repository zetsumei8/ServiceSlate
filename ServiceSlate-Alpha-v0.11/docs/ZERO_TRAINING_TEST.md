# Zero-Training Usability Test

Give this list to a person who has never used ServiceSlate. Do not explain how to complete the tasks.

## Office user
1. Find Future Ford of Clovis.
2. Find what was previously done to its Challenger lift.
3. Create a new service request.
4. Schedule it for a service day.
5. Prepare customer confirmation.
6. Review a FastField submission.
7. Approve technician paperwork.
8. Back up ServiceSlate.

## Technician
1. Open today's assigned work.
2. Find the equipment's prior service context.
3. Add finding/correction/verification.
4. Add a measurement and photo.
5. Submit the work.
6. Close/reopen the browser and verify unfinished work remains.

## Pass rule
Any step that requires verbal explanation, hidden knowledge, or uncertainty about whether data saved is a UX defect to review. Do not solve failures by adding a long tutorial when the screen itself can be made clearer.
